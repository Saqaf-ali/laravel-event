# Event Core Platform - Full-Stack SaaS Event Marketplace & Analytics Dashboard 🎫

A comprehensive, production-grade Event Management and Ticketing ecosystem featuring both an ultra-modern client-facing marketplace and a high-performance administration dashboard. Built as a seamless single-page application (SPA), this platform handles complex event scheduling, multi-tier ticket commerce, secure checkout pipelines, and real-time digital ticket generation.

## 🛠️ Tech Stack & Architecture
- **Backend Infrastructure:** PHP / Laravel Framework (Structured with clean Domain-Driven patterns & strict SOLID principles)
- **Frontend Architecture:** Vue.js (Component-driven Single Page Application workflow)
- **UI Component Engine:** Shadcn Vue (Tailwind CSS driven, accessible layout tokens, high-end responsive grids)
- **Data Synchronization:** Inertia.js (Monolithic feel with single-page app reactivity and zero-API overhead)
- **Database Layer:** MySQL (Relational architecture fully optimized for rapid checkout transactions and real-time capacity tracking)

## ✨ Comprehensive Feature Suite

### 🌐 Client-Facing Marketplace (B2C Interface)
- **Dynamic Event Discovery:** A clean, responsive storefront where users can explore available events, filter by categories, and check precise dates, times, and venue locations.
- **Multi-Tier Ticket Selection:** Fluid user experience showing different ticket classes (e.g., VIP, General Admission) with accurate real-time availability pricing.
- **Reactive Shopping Cart & Checkout:** A secure, native checkout pipeline built for high-concurrency ticket locking during checkout.
- **"My Orders" Hub:** A dedicated user portal tracking purchase histories, order details, and statuses.
- **Digital Barcode/QR Generation:** Every purchased ticket dynamically renders a unique barcode/QR code token on the user's dashboard for instant event-day validation.

### 📊 Admin Administration Suite (SaaS Dashboard)
- **Flawless Dark / Light Mode System:** Fully integrated native theme toggle utilizing Tailwind variables for a dynamic visual transition across all complex tables, sidebars, and dialogue components.
- **Live Analytics Panels:** Monitoring total sales revenue, active attendee conversion rates, event capacities, and ticket depletion metrics with highly polished charts and metric cards.
- **Granular Inventory & Tiering Control:** Advanced backend validation handling dynamic price variations and preventing over-allocation of ticket limits per tier.
- **Data Management Hub:** Robust tables featuring real-time searching, status badges, and inline actions to manage event constraints efficiently.
